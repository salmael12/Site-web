# Présentation VPN Server - Projet Complet

## 📊 Présentation PowerPoint Créée

Ce projet contient une présentation PowerPoint professionnelle complète sur la mise en place d'un serveur VPN sécurisé sous Windows Server 2019 et Linux Ubuntu.

## 📁 Fichiers disponibles

- **VPN_Server_Presentation.pptx** - Présentation PowerPoint (20 diapositives)
- **create_vpn_presentation.py** - Script Python pour générer la présentation
- **PRESENTATION_INFO.md** - Documentation détaillée de la présentation

## 🎯 Contenu de la présentation

### Thème principal
**"Implémentation d'un VPN sécurisé (IPSec et SSL) sous Windows Server 2019 et Linux pour la connexion à distance des employés"**

### 20 diapositives couvrant:

1. ✅ Titre et introduction
2. 📋 Plan de la présentation
3. 🧠 Contexte du projet (télétravail, sécurité)
4. ⚙️ Objectifs détaillés
5. 🧩 Outils et technologies (VirtualBox, Windows Server, Ubuntu, OpenVPN, StrongSwan)
6. 🏗️ Architecture réseau et topologie
7. 🪟 Configuration Windows Server 2019 (RRAS)
8. 💻 Commandes PowerShell
9. 🐧 Configuration Linux Ubuntu (OpenVPN/StrongSwan)
10. 💻 Commandes OpenVPN
11. 🔒 Sécurisation et authentification (AES-256, certificats)
12. ✅ Tests et validation
13. 🔍 Analyse du trafic avec Wireshark
14. ⚖️ Comparaison Windows vs Linux
15. 🎯 Résultats attendus
16. ⚠️ Problèmes courants et solutions
17. 📚 Documentation et livrables
18. 🚀 Améliorations futures
19. 🎓 Conclusion
20. ❓ Questions

## 🚀 Utilisation

### Ouvrir la présentation
```bash
# Avec LibreOffice (Linux)
libreoffice --impress VPN_Server_Presentation.pptx

# Ou simplement double-cliquer sur le fichier
```

### Régénérer la présentation
```bash
# Installer les dépendances
pip install python-pptx

# Exécuter le script
python3 create_vpn_presentation.py
```
